## Mengganti foto
Ganti berkas `photo-placeholder.svg` dengan foto Anda, atau ubah elemen gambar di `index.html` ke nama file foto lain.

## Menjalankan di GitHub Pages
1. Buat repository baru di GitHub.
2. Tambahkan semua berkas ke repository.
3. Aktifkan GitHub Pages di branch `main` atau `master`.
4. Akses situs dari alamat GitHub Pages yang disediakan.
